# v2.3 GPT-6 Luna: four-dataset comparison experiment results

## Run setup

Four full-dataset experiments were run sequentially on the selectable v2.3 pipeline, with GPT-6 Luna as the query-agent model. The released default remains v2.2. Each experiment uses the full Langfuse dataset snapshot and was recorded as a distinct dataset run.

The comparison below uses the previous full-dataset v2.2 answer correctness means and the latest v2.3 means. Both metrics are named `answer_correctness_v2`. The older v2.2 runs used managed evaluator version 1 and earlier dataset snapshots; the v2.3 runs used evaluator version 2 and newer snapshots. The item IDs match across the paired snapshots, but expected answers/fact versions changed. Treat the changes as directional comparisons rather than a controlled, evaluator-identical A/B result.
