From question to cited answer

The full pipeline searches book passages with several phrasings, selects evidence from complementary indexes, and writes an answer with inspectable citations.

These lanes show separate search routes, not concurrent jobs. Translation, when needed, supplies the wording for HyDE, alternatives, and grammar correction. Name completion contributes only to the wider candidate pool.

Evidence sources and optional paths

These indexes and query-time paths feed evidence selection above. The disabled graph is shown for completeness.

Default flags: keyword_hits, scene_moment, scene_context, entity_names, and entity_matrix are on; entity_graph is off. A low reranker score expands the evidence to 15 passages and enables answer reasoning. Model names and thresholds are configurable.
