Millennium semantic search · Architecture

From question to cited answer

The default full mode turns one user question into several semantic searches, narrows the results in three pools, and writes an answer from selected book passages.

The optional seventh search completes a name found in the books. Its matches join the wider pool and do not change the six-search fusion. Langfuse supplies versioned prompts and records the stages; it does not perform the book lookup. Model names and endpoints can be configured.
